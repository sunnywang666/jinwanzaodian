# 「今晚早点」界面设计说明 v5

> 这份文档给设计师看，描述所有界面的内容、元素、跳转关系与视觉风格。
> 与《产品概念文档 v5》配套。本版相对旧版的主要更新：
> 1. 用户身份明确为**店长**；新增常驻伙伴**面点精灵**及其**小屋**界面。
> 2. "打烊场景"拆为**傍晚（预承诺）**与**夜晚（打烊仪式 + 放下手机）**两段，新增**熄灯陪伴状态**。
> 3. 菜单页**删除"早餐墙翻牌（真实早餐照）"**交互（拍真实早餐已剥离为姊妹产品）。
> 4. onboarding 改为**测评定精灵灵魂 → 选外表 → 起名 → 开张**。
> 5. 主画面新增**白天状态（备菜打理 + 可选午睡点缀）**；铺子时间跟现实同步。
> 6. 视觉方向确定为**手绘治愈暖调**（已有提示词套组），像素风仅作备选。

## 二、各界面详细说明

### 界面 1：铺子主画面

**定位**：App 核心首页，用户大部分时间看到的画面。铺子时间跟现实同步，全天开着、只在夜里打烊。

**画面内容**：早点铺室内全景，从店长视角看过去。

**固定元素（铺子的"家具"，同时是功能入口）**：

| 物件 | 位置建议 | 点击跳转 | 说明 |
|------|---------|---------|------|
| 菜单板 | 墙上左侧 | 菜单页（菜品） | 木质菜单牌，挂着这铺子会做的早点 |
| 电话本 / 联络簿 | 柜台上 | 客人图鉴页 | 一本翻旧的小册子，记着来过的客人 |
| 账本（营业日志） | 柜台上 | 营业日志页 | 一本厚厚的手写账本 |
| 收音机 | 窗台/柜台角 | 白噪音页 | 复古收音机（优先级低，demo 可省） |
| 黑板 / 留言板 | 墙上显眼处 | 留言板页 | 客人留下的便签、铺子的碎语 |
| **精灵小屋** | 柜台后/角落 | 精灵换装与皮肤陈列页 | **新增**：面点精灵的家，也是它夜里睡觉的地方 |
| 招牌 | 门口上方 | 无 | 写"今晚早点"，显示营业状态 |
| 窗户 | 墙上 | 无 | 透出天色，跟现实时间同步（晨光/白昼/夕阳/月夜） |
| 柜台 | 画面中下部 | 无 | 摆着今天的早点 |

**常驻角色**：
- **面点精灵**：一直在铺子里陪着店长。白天和店长一起备菜打理、午睡时一起打盹、夜里回小屋睡。是 AI 对话的化身（想聊点它就在）。
- **今天的客人（小动物）**：数量/种类取决于近期作息（见概念文档"铺子状态的度"）。静态出现，不同时段不同状态。

**动态元素**：

| 元素 | 变化逻辑 |
|------|---------|
| 窗外天色 | 跟手机真实时间走：晨光→白昼→夕阳→月夜 |
| 铺子氛围（三档） | 热闹 / 平常 / 安静，由近期作息趋势决定；**最差也只是"安静"，永不冷场关张** |
| 客人 | 早上吃早点、白天闲坐/离开、随状态出现稀有客人 |
| 柜台上的早点 | 当天清晨营业出过的菜会摆出来 |
| 精灵姿态 | 随时段变：清晨迎客、白天备菜、午后打盹、夜里回小屋 |

**底部状态栏**：一行温柔文字，随时段变（清晨"早呀，今天阿橘来了"／白天"备点明天的料吧"／傍晚"今晚想几点关灯歇着？"）。

### 界面 2：开门场景（清晨 overlay）

**触发**：当天第一次打开 App。
**节奏（关键）**：先迎接 → 再结算昨天（轻）→ 再开启今天，**不一股脑砸信息**。

- **先迎接**：精灵一句带着昨晚记忆的话把人接住。
- **结算昨天**：昨晚打烊/熄屏的温柔反馈（精灵的话 + 铺子今天的状态）；昨晚没好好打烊时，黑板补问"昨晚大概几点放下手机的呀？"
- **开启今天**：出餐给来吃早点的客人、看今天来了谁。
- 开门时刻 = 天然的"我醒了"信号（睡眠窗口的右端点）。

---

### 界面 3a：傍晚·准备打烊（预承诺 overlay）

**触发**：傍晚（约用户设定的提醒时间）。此刻用户还理智，是 AI 的核心窗口。
- **设今晚关灯时间**：精灵问"明天阿橘要来，今晚打算几点关灯歇着呀？" → 用户选时间（=今晚就寝目标/预承诺）。
- **卸下心事（对话）**：可展开"今晚有什么放不下的事吗？"，趁清醒帮用户把第二天待办清出大脑（CBT-I）。
- **明天预告**：把"早睡"翻译成"我答应了客人"。

> 这是"准备打烊"，**不是打烊**。铺子白天本就开着，这一步只是定下今晚几点关灯。

### 界面 3b：夜晚·打烊（打烊 overlay）

**触发**：到了用户设的关灯时间。
- **通知**：精灵先提示"要打烊了哦"。
- **打烊界面**：主语是"**铺子要打烊了 / 该关灯歇业了**"，**不是"你该睡了"**。
- **打烊仪式**：关灯 / 拉卷帘 + 几次呼吸（原呼吸引导归位于此）；精灵回小屋睡。
- **放下手机引导**：最后一屏不是"晚安"，是"铺子睡了，把手机也放下吧，扣过来放远一点"。
- 完成 = 记录今晚关灯时间（睡眠窗口的左端点）。
- **熄灯陪伴状态**：铺子安静、精灵打哈欠、轻微环境光，且**越来越安静**（光渐柔/音渐弱），目的是让屏幕变无聊到用户自然熄屏。可轻轻引导"你也可以关掉屏幕，铺子会自己守夜"。
- 没在设定时间打烊也**不催、不惩罚**，第二天铺子安静些而已。

---

### 界面 4：客人图鉴页（入口：电话本）

**从哪里进入**：点柜台上的电话本/联络簿。

**每位客人一页档案**：长相、名字、性格签名（一句话）、最爱的早餐、来店次数、第一次来的日期、**与店长的熟络程度（v5 新增）**。未解锁是模糊剪影 + 解锁提示。

**关系递进暗线**：客人来熟了（达到一定来访次数）会"教你一道它家乡的菜"——既解锁一道菜品，也是交情到位的证明（详见概念文档第十三节）。

---

### 界面 5：菜单页（入口：菜单板）

**从哪里进入**：点墙上的菜单板。

**页面结构**：
- 顶部：标题"铺子菜单" + 收集进度（已会做 X / Y 道）。
- 分区 1：常见早点（16–20 种）。
- 分区 2：限定 / 联名款（3–5 种，锁定）。

**每道菜卡片**：
- 已解锁：插画 + 菜名 + 做过几次 + 哪些客人爱吃 + **怎么来的（里程碑研发 / 哪位熟客教的）**。
- 未解锁：浅灰手绘轮廓 + "还没出现在你的铺子里"。

> **删除**：旧版"早餐墙翻牌（正面真实早餐照、背面数字早点）"交互——随拍真实早餐剥离一并去掉。本页是"铺子手艺收集"，不涉及用户真实早餐照片。

---

### 界面 6：营业日志页（入口：账本）

**从哪里进入**：点柜台上的账本。
**形态**：像一本手写账本/日记，**不是科技感数据仪表盘**。

**内容（两层）**：
1. **每天一行的流水**：几点开门（=几点醒）、几点关灯（=几点睡/放下手机）、夜里安静陪到打烊还是中途出门、来了几位客人。
2. **翻回去看的趋势**（攒一两周后）：近期普遍几点关灯、最早/最晚是哪天、连着早睡了几个早晨、当前连续开门天数。**这一层是产品真正的"健康产出"**。
   - 关门时间走势：最近 7/30 天折线，**手绘风，不要科技感**。
   - 精灵在旁边偶尔一句**温柔的店长解读**（"这周你周三总关灯最晚，是不是周三有什么固定的事？"）。

---

### 界面 7：留言板页（入口：黑板）

**从哪里进入**：点墙上的黑板/留言板。
**内容**：客人留下的话，每天按铺子状态生成。日常留言（"今天的油条很好吃！——阿橘"）、状态触发留言（连开 3 天后"我明天会来哦"）、安静时的纸条（"没关系，明天见 ——铺子"）。
**设计要点**：像贴在黑板上的便签纸，颜色/角度随意而温馨，偏装饰收集，不呈现数据。

---

### 界面 8：白噪音页（入口：收音机）

**内容**：雨声/风声/咖啡馆/壁炉等白噪音；呼吸引导（不想走打烊仪式时可在此独立用）。
**设计要点**：做成一台收音机，转旋钮换频道。**优先级低，demo 可简化或省略**。

---

### 界面 9（新增）：精灵小屋页（入口：精灵小屋）

**从哪里进入**：点铺子里的精灵小屋。
**三合一**：
1. **换装/选形态**：给精灵换/看已解锁的点心形态（本体白面 + 各种点心样子，一双豆豆眼不变）。
2. **皮肤陈列**：解锁过的形态像摆件陈列，未解锁是空位/剪影。
3. **夜间归处**：夜里打烊后精灵回这里睡——画面上体现"铺子跟店长一起歇着"。

**解锁逻辑提示**：皮肤是长期里程碑奖励，只靠**累计熄屏早睡的夜晚**解锁，**不靠连续、断了不清零**。

---

### 界面 10：新用户开店流程（onboarding）

**触发**：第一次打开 App。
**流程（v5 改版）**：
1. **欢迎**："欢迎来到你的早点铺。"
2. **轻量测评**：3–5 个简单问题，**用来决定你的面点精灵是哪一型的灵魂**（对应六型，即它懂你哪一种夜晚）。包装成"看看哪只精灵最懂你"，不叫"人格诊断"。
3. **精灵登场 + 选外表**："这是属于你的伙伴，它最懂那种……的夜晚。"然后让用户**给它挑一个点心外表**。
4. **起名**：给精灵起个名字。
5. **设关灯时间**："你平时希望几点关灯歇着？这只是参考，铺子不会催你。"
6. **开张**：铺子全貌 + 第一批客人在门口，"开门吧！"

目标关灯时间（可改）、提醒设置（傍晚提醒开关/时间）、数据权限（HealthKit/Health Connect）、关于/反馈。

## 三、视觉风格

### 已确定方向：手绘治愈暖调

（沿用《UI 设计提示词套组》的母风格）cozy whimsical hand-drawn UI：绘本/手帐/蜡笔/水彩质感，边缘轻微不规则，朴素可爱松弛；**不要**商业精修、玻璃拟态、3D、赛博科技感。

**色板**：warm cream white、soft beige、muted sage green、dusty coral、pale blue、butter yellow、warm brown、soft charcoal black。低饱和、温柔、不刺眼。

> 像素复古风（星露谷向）作为备选保留，但当前主推手绘。

### 不变的视觉原则

1. 整体氛围：温暖、安全、让人想待着。
2. 窗外天色跟现实时间同步——铺子最大的动态视觉元素。
3. 可交互物件有微妙提示（微微发光/轻晃/不同材质）。
4. 夜间打烊后铺子色调明显变暗变暖，降低屏幕刺激。
5. 文字用温柔语气、手写笔迹感，中文为主。

## 五、与旧版/旧应用素材的关系

旧《UI 设计提示词套组》是上一代"助眠对话 App"写的，**画风基底（手绘治愈风、色板）继续沿用**，但以下内容已过时、不要再按它做：锁屏式干预页、六动物人格按钮作为核心、"入睡小动物收藏"、"早餐记录/早餐图鉴(拍真实早餐)"。新的人格逻辑收敛进了**面点精灵的灵魂**（onboarding 一次性），核心收集是**客人图鉴 + 菜单 + 精灵皮肤**。
